# 10 — Lộ trình

Mỗi mốc phải: **chạy được** (`docker compose up` hoặc `pnpm start:dev`), **có test xanh**, **cập nhật `openapi.json`**, và có file plan `docs/plans/Mx-*.md` được viết **trước khi code**.

| Mốc                                       | Nội dung                                                                                                                                                                                                          | Chạy được gì cuối mốc                                                                       | Điều sẽ học                                                                                                                  |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **M0 — Khung**                            | pnpm + Nest 12 ESM, config validate, pino + requestId, error filter, versioning, Swagger `/docs`, health, Drizzle + migration đầu (extension, `f_unaccent`, text search config), entry worker, Docker Compose, CI | `GET /health/ready` xanh, `/docs` mở được, worker khởi động, e2e harness với Testcontainers | Bootstrap Nest, DI, module động (`forRootAsync`), bẫy ESM, Swagger plugin, Testcontainers, hai tiến trình chung một codebase |
| **M1 — Auth**                             | users, register/login (argon2id), access JWT, refresh rotation + phát hiện reuse, `JwtAuthGuard` global, `@Public`, `@CurrentUser`, sessions                                                                      | Đăng ký → login → gọi `/me` → refresh → logout bằng Swagger (nút Authorize)                 | Guard global, custom decorator, `FOR UPDATE` đầu tiên, test concurrency đầu tiên                                             |
| **M2 — Tổ chức (lõi)**                    | Tạo org, org của tôi, danh sách thành viên (cursor + search không dấu), đổi vai trò, gỡ thành viên, `OrgMemberGuard`, policy + `@Require`                                                                         | Owner quản lý thành viên. Member bị chặn đúng ma trận                                       | Guard nhiều tầng, policy thuần, cursor pagination, pg_trgm + unaccent                                                        |
| **M3 — Mời, duyệt, chuyển sở hữu, audit** | Link mời (hash token, max_uses), accept, join request + duyệt, chuyển sở hữu, rời org, `AuditModule`                                                                                                              | Luồng mời → duyệt → vào org. Audit log xem được                                             | UPDATE nguyên tử, khoá nhiều dòng theo thứ tự, partial unique index, audit trong transaction                                 |
| **M4 — Kênh**                             | CRUD kênh, public/private, join/leave, thành viên + vai trò, chuyển chủ kênh, lưu trữ, xoá mềm + job purge, `ChannelAccessGuard`, 404 cho kênh ẩn                                                                 | Ma trận quyền kênh pass toàn bộ e2e dạng bảng                                               | Composite FK, mutex bằng row lock, `SKIP LOCKED`, test quyền theo bảng                                                       |
| **M5 — Upload**                           | Storage module (S3), init/part/status/complete/abort, stream không buffer, idempotency key, dọn upload hết hạn                                                                                                    | Upload file 500 MB, ngắt giữa chừng, resume, complete → meeting `queued`                    | Stream & backpressure, S3 multipart, idempotency, giới hạn body                                                              |
| **M6 — Pipeline xử lý**                   | Queue + processor: preprocess (ffmpeg), transcribe (whisper.cpp), summarize (LLM), state machine, retry, fake providers, share meeting vào kênh, quyền xem meeting                                                | Upload xong → transcript + tóm tắt tự xuất hiện                                             | Worker tách tiến trình, BullMQ flow/retry/backoff, child process, job idempotent, graceful shutdown                          |
| **M7 — Realtime**                         | Socket.IO gateway, auth handshake, rooms, Redis adapter, emitter từ worker, hết hạn token                                                                                                                         | Trang HTML thử thấy `%` tiến độ chạy                                                        | WebSocket auth, fan-out nhiều instance, pub/sub                                                                              |
| **M8 — Transcript**                       | API segment, full-text search (tsvector + `ts_headline`), xuất SRT/VTT (stream)                                                                                                                                   | Tìm "ke hoach" ra đoạn "kế hoạch" kèm timestamp. Tải file .srt                              | FTS Postgres, generated column, streaming response                                                                           |
| **M9 — Báo cáo tuần**                     | Job scheduler cron có tz, tick fan-out, generate, quota tạo lại, phiên bản, bật/tắt, backfill                                                                                                                     | Kích hoạt tick thủ công → báo cáo cho kênh có ≥ 2 meeting                                   | Cron đa instance, múi giờ, idempotency theo khoá tự nhiên                                                                    |
| **M10 — Thông báo**                       | Tạo thông báo (dedupe), danh sách cursor, đếm chưa đọc, đọc/đọc hết, xoá mềm, push realtime sau commit                                                                                                            | Nhận thông báo realtime khi báo cáo xong / được thêm vào kênh                               | Publish sau commit, partial index, outbox (tuỳ chọn)                                                                         |
| **M11 — Hardening** (tuỳ chọn)            | Rate limit, RLS làm lớp phòng thủ 2, presigned upload, OpenTelemetry, nâng Node 26 LTS                                                                                                                            |                                                                                             | Phòng thủ nhiều lớp, quan sát hệ thống                                                                                       |

Thứ tự này có chủ ý: mỗi mốc dùng lại những thứ mốc trước đã dựng. Nếu muốn làm điểm hấp dẫn sớm (Whisper) để có động lực, có thể làm thử nghiệm M6 ở một nhánh riêng sau M1.
